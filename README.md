# Sistema de Controle de Serviços - 2Pi Studio

Este projeto tem como objetivo o desenvolvimento de um sistema web para organizar e controlar os serviços prestados pela empresa 2Pi Studio. Ele permitirá o cadastro de funcionários, clientes e equipamentos, além da alocação de recursos e visualização de dados financeiros.

## 📌 Funcionalidades Principais

- Cadastro de funcionários, clientes e equipamentos
- Criação e acompanhamento de serviços
- Alocação de mão de obra e equipamentos por serviço
- Visualização de agenda/kanban dos serviços
- Envio de feedbacks pelos funcionários
- Dashboards financeiros por serviço e geral
- Controle de acesso ao sistema

## 🛠️ Tecnologias Utilizadas

- HTML, CSS, JavaScript
- Node.js (Backend)
- MySQL (Banco de dados)
- Git e GitHub (Versionamento)
- Postman (Testes de API)
- Visual Studio Code (IDE)
